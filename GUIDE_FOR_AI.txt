🔧 СИСТЕМА ПРОКСИ
═══════════════════════════════════════════════════════════════════

📌 ОПИСАНИЕ:
Бот использует прокси для подключения к Telegram API.
Прокси загружаются из папки ../proxy_manadger/good_proxies.txt

📌 АЛГОРИТМ РАБОТЫ:
1. При запуске бот загружает все прокси из файла
2. Проверяет их работоспособность через Telegram API (пингование)
3. Выбирает самый быстрый рабочий прокси
4. Подключается через него
5. При ошибке (таймаут, соединение) — переключается на следующий по пингу
6. Если все прокси перепробованы — работает без прокси

📌 КЭШИРОВАНИЕ:
Результаты пингования сохраняются в proxy_pings_cache.json на 10 минут

📌 ВАЖНОЕ ПРАВИЛО:
НЕ МЕНЯТЬ СИСТЕМУ ПОДКЛЮЧЕНИЯ В main.py!
Используется только AiohttpSession(proxy=proxy_url).
Любые другие варианты (connector, ssl_context) — ЗАПРЕЩЕНЫ!

═══════════════════════════════════════════════════════════════════
📢 НАПОМИНАЛКА ДЛЯ НЕЗАРЕГИСТРИРОВАННЫХ ПОЛЬЗОВАТЕЛЕЙ
═══════════════════════════════════════════════════════════════════

📌 ОПИСАНИЕ:
Когда пользователь пишет в чат, бот проверяет, есть ли он в базе.
Если нет — каждое 5-е сообщение напоминает о регистрации.

📌 АЛГОРИТМ:
1. При каждом сообщении в чате проверяется регистрация пользователя
2. Счётчик сообщений увеличивается для незарегистрированных
3. На каждом 5-м сообщении отправляется напоминание
4. Счётчик сбрасывается после напоминания

📌 ПРИВЕТСТВИЕ НОВЫХ:
Когда пользователь заходит в чат, бот отправляет приветствие с инструкцией.

📌 КОМАНДА /update:
Позволяет проверить статус регистрации и получить ссылку на бота.

📨 БОТ-ПЕРЕСЫЛЬЩИК (forward_bot)
═══════════════════════════════════════════════════════════════════

📌 ОПИСАНИЕ:
Отдельный бот для пересылки сообщений в админ-группу.
Работает независимо от основного бота.

📌 КОМАНДЫ:
/start          — Приветствие
/admin_add      — Добавить администратора (владелец)
/admin_remove   — Удалить администратора (владелец)
/admins         — Список администраторов
/stats          — Статистика

📌 НАСТРОЙКИ:
Пересылка работает через прокси (если включено).
Анонимный режим — скрывает имя отправителя.

═══════════════════════════════════════════════════════════════════
⚠️ ВАЖНЫЕ ПРАВИЛА
═══════════════════════════════════════════════════════════════════

1. НЕ МЕНЯТЬ СИСТЕМУ ПОДКЛЮЧЕНИЯ
   Используется только AiohttpSession(proxy=proxy_url).
   Любые другие варианты (connector, ssl_context) — ЗАПРЕЩЕНЫ!

2. КОМАНДЫ, НЕДОСТУПНЫЕ ВО ФЛУДЕ:
   - /apply, /free, /cancel_request, /rest

3. ВО ФЛУДЕ РАБОТАЮТ:
   - /start, /help, /about, /aboutme
   - /members, /roles
   - /call, /callfal (для админов)

4. ПЕРЕСЫЛКА СООБЩЕНИЙ
   - Пересылка выполняется отдельным ботом forward_bot
   - Основной бот НЕ пересылает сообщения

═══════════════════════════════════════════════════════════════════
🐛 ИЗВЕСТНЫЕ БАГИ И ИХ РЕШЕНИЯ
═══════════════════════════════════════════════════════════════════

1. Кнопки не работают:
   → Проверить, что все обработчики зарегистрированы в __init__.py
   → Проверить, что текст кнопки точно совпадает с F.text
   → Добавлено логирование для отладки

2. /apply во флуде:
   → Добавлена проверка if message.chat.id == GENERAL_CHAT_ID

3. Напоминалка не работает:
   → Проверить, что chat_member_router добавлен в __init__.py
   → Проверить, что функция check_user_registration обрабатывает сообщения в чате
