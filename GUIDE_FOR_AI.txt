📌 ОПИСАНИЕ ПРОЕКТА
═══════════════════════════════════════════════════════════════════

LoezF_Bot — это специализированный Telegram-бот для управления процессом принятия новых участников (нью) в флуд-чаты и ролевые сообщества. Бот создан для автоматизации и упрощения работы администраторов с заявками, ролями и рестами.

🔹 ОСНОВНАЯ ЦЕЛЬ И АУДИТОРИЯ:
───────────────────────────────────────────────────────────────────
• Цель: Автоматизация приёма новых участников (нью) в флуд-чаты через систему заявок.
• Аудитория: Участники фандомов и ролевых сообществ, администраторы флуд-чатов.

🔹 КЛЮЧЕВЫЕ ВОЗМОЖНОСТИ:
───────────────────────────────────────────────────────────────────
• 📝 Система принятия нью — пользователи подают заявки через бота, администраторы одобряют или отклоняют их.
• ⏳ Управление рестами — временная "заморозка" роли с автоматическим снятием.
• 📢 Калы (созывы) — массовые упоминания участников для сбора в чате.
• 👑 Управление администраторами — гибкая система рангов (владелец, админ, модератор).
• 📊 Статистика и списки — полная информация о пользователях, ролях и их статусах.
• 🔍 Диагностика и настройки — инструменты для мониторинга и настройки бота.
• 🌐 Поддержка прокси — автоматическое переключение на рабочие прокси.
• 📨 Отдельный бот-пересыльщик — для анонимного общения игроков с администрацией.

🔹 АРХИТЕКТУРА И ХРАНЕНИЕ ДАННЫХ:
───────────────────────────────────────────────────────────────────
• Язык: Python 3.14
• Фреймворк: Aiogram 2.25.1
• База данных: SQLite (bot.db) — для хранения истории и основных данных
• Файловое хранилище:
  - data/roles_status.json — статусы всех ролей (занята/свободна/рест)
  - data/users/users.txt — список зарегистрированных пользователей
  - data/admins/admins.txt — список администраторов с рангами
  - data/system_settings.json — настройки бота (кулдауны, включение/отключение функций)
• Прокси: Автоматическая загрузка из ../proxy_manadger/good_proxies.txt
• История действий пользователей: Сохраняется в data/users_history/ (JSON-файлы по ID)

🔹 ПРАВИЛА И ОГРАНИЧЕНИЯ:
───────────────────────────────────────────────────────────────────
• Основной функционал (заявки, ресты, настройки) доступен только в личных сообщениях с ботом.
• Во флуд-чате бот показывает только минимальную информацию (количество участников, список ролей без кнопок).
• Клавиатура бота отображается только в личных сообщениях и скрывается во флуде.
• Управление администраторами (повышение/понижение) доступно только владельцу.
• Система подключения к Telegram API через прокси строго фиксирована (AiohttpSession(proxy=proxy_url)) и не подлежит изменению.

🔹 УПРАВЛЕНИЕ СИСТЕМОЙ:
───────────────────────────────────────────────────────────────────
• Глобальные команды для удаления данных и участников:
  - /resetuser [ID] — полный сброс пользователя (удаление из списка + освобождение роли)
  - /removeuser [ID] — удаление пользователя из списка
  - /close — закрытие набора новых участников
  - /open — открытие набора новых участников
• Логирование: Все действия администраторов логируются для аудита.

🔹 БУДУЩЕЕ РАЗВИТИЕ (ПЛАНИРУЕТСЯ):
───────────────────────────────────────────────────────────────────
• Регулярные обновления: Бот будет обновляться каждый месяц для исправления багов и добавления новых функций.

═══════════════════════════════════════════════════════════════════
🔧 СИСТЕМА ПРОКСИ
═══════════════════════════════════════════════════════════════════

📌 ОПИСАНИЕ:
Бот использует прокси для подключения к Telegram API.
Прокси загружаются из папки ../proxy_manadger/good_proxies.txt

📌 АЛГОРИТМ РАБОТЫ:
1. При запуске бот загружает все прокси из файла
2. Проверяет их работоспособность через Telegram API (пингование)
3. Выбирает самый быстрый рабочий прокси
4. Подключается через него
5. При ошибке (таймаут, соединение) — переключается на следующий по пингу
6. Если все прокси перепробованы — работает без прокси

📌 КЭШИРОВАНИЕ:
Результаты пингования сохраняются в proxy_pings_cache.json на 10 минут

📌 ВАЖНОЕ ПРАВИЛО:
НЕ МЕНЯТЬ СИСТЕМУ ПОДКЛЮЧЕНИЯ В main.py!
Используется только AiohttpSession(proxy=proxy_url).
Любые другие варианты (connector, ssl_context) — ЗАПРЕЩЕНЫ!

═══════════════════════════════════════════════════════════════════
📢 НАПОМИНАЛКА ДЛЯ НЕЗАРЕГИСТРИРОВАННЫХ ПОЛЬЗОВАТЕЛЕЙ
═══════════════════════════════════════════════════════════════════

📌 ОПИСАНИЕ:
Когда пользователь пишет в чат, бот проверяет, есть ли он в базе.
Если нет — каждое 5-е сообщение напоминает о регистрации.

📌 АЛГОРИТМ:
1. При каждом сообщении в чате проверяется регистрация пользователя
2. Счётчик сообщений увеличивается для незарегистрированных
3. На каждом 5-м сообщении отправляется напоминание
4. Счётчик сбрасывается после напоминания

📌 ПРИВЕТСТВИЕ НОВЫХ:
Когда пользователь заходит в чат, бот отправляет приветствие с инструкцией.

📌 КОМАНДА /update:
Позволяет проверить статус регистрации и получить ссылку на бота.
