📌 ОПИСАНИЕ ПРОЕКТА (ДЛЯ НОВОЙ ИИ)
═══════════════════════════════════════════════════════════════════

LoezF_Bot — Telegram-бот для управления приёмом новых участников (нью)
во флуд-чаты и ролевые сообщества.

⛔ ВАЖНО: Проект полностью завершён и стабильно работает.
⛔ НЕ ТРОГАТЬ СИСТЕМУ ПОДКЛЮЧЕНИЯ!
⛔ НЕ МЕНЯТЬ СТРУКТУРУ БЕЗ СОГЛАСОВАНИЯ!
⛔ ЛЮБЫЕ ИЗМЕНЕНИЯ ТОЛЬКО ПО СОГЛАСОВАНИЮ С ВЛАДЕЛЬЦЕМ!

🔹 ОСНОВНАЯ ЦЕЛЬ:
Автоматизация приёма новых участников (нью) во флуд-чаты.

🔹 АУДИТОРИЯ:
Участники фандомов и ролевых сообществ.

🔹 КЛЮЧЕВЫЕ ФУНКЦИИ:
✅ Приём нью через систему заявок
✅ Управление ролями и рестами
✅ Калы (созывы участников)
✅ Управление администраторами (ранги 1-3)
✅ Полная диагностика и настройки
✅ Поддержка прокси (автоматическое переключение)

🔹 ТЕХНОЛОГИИ:
🐍 Python 3.14.4
🤖 aiogram 3.17.0 (НЕ ОБНОВЛЯТЬ — см. раздел про версии)
🗄️ SQLite (bot.db)
📁 JSON-файлы для данных

🔹 АРХИТЕКТУРА:
handlers/ — все обработчики команд
utils/ — вспомогательные функции
data/ — хранение данных
config.py — настройки
main.py — точка входа

ПРОД: LoEZF_Bot (рабочий бот, реальные юзеры)

⚠️ КРИТИЧЕСКИЕ ПРАВИЛА AIOGRAM 3.x
═══════════════════════════════════════════════════════════════════

❌ InlineKeyboardButton("текст", callback_data="...") — НЕ РАБОТАЕТ!
✅ InlineKeyboardButton(text="текст", callback_data="...") — правильно

❌ @router.message(F.text == "/apply") — не работает для команд!
✅ @router.message(Command("apply")) — правильно

❌ InlineKeyboardButton(callback_data="...") без text= — упадёт с ошибкой:
"BaseModel.init() takes 1 positional argument but 2 were given"
✅ Всегда передавать text= именованным аргументом

📌 Причина: в aiogram 3.x InlineKeyboardButton — Pydantic BaseModel,
который принимает ТОЛЬКО именованные аргументы.

Дата последнего обновления: 18.09.2026

Список последних изменений:

[7.3.0] - Зафиксированы версии библиотек (aiogram 3.17,
aiohttp 3.13.5, aiohttp-socks 0.11.0, python-socks 2.8.2).
Причина: обновлённые версии ломают подключение через прокси.
Создана тестовая копия проекта (LoEZF_Bot_test) для безопасных
экспериментов.

[7.2.0] - Порядок роутеров (keyboards перед chat_member),
удалены заглушки /regc /unregc /call /callfal из base_commands,
unsubscribed_calls переведён на .json со словарём,
добавлена команда /message_all (FSM, рассылка владельцем),
apply_states убран из роутеров,
новое правило чтения файлов через код-блок

[7.1.0] - JSON-формат для users/admins/requests,
приоритетный прокси + PING_COUNT=1, MAX_CONCURRENT=200,
FSM для настроек, chat_member пропускает команды,
add_user/add_admin из utils

[7.0.0] - Переход на aiogram 3.x, requests.json — словарь, логи в data/logs,
удаление role_commands.py, логика рангов при одобрении,
абсолютные пути через .resolve()

[6.2.0] - Исправлен баг 'str' object has no attribute 'get', переписан role_utils.py

[6.1.0] - Добавлены правила удаления кода, справочник функций

[5.5.0] - Управление админами, настройки, диагностика

[5.4.1] - Удалена пересылка из основного бота, чистка кода

[5.4.0] - Добавлена напоминалка, /update, управление пересылкой

[5.3.0] - Система прокси с пингованием, ускорение, переключение

[5.2.0] - Бот-пересыльщик

[5.1.0] - Рефакторинг, Proxy Manager

[5.0.0] - Первоначальная структура
