# 🧠 AI_CONTEXT.md — Память и заметки для ИИ

Этот файл создан для сохранения контекста разработки бота LoEzF_Bot. 
Любая новая модель ИИ должна прочитать этот файл ПЕРЕД началом работы.

## 🏗️ Архитектурные правила проекта
1. Все данные пишутся/читаются ТОЛЬКО через `src/utils/parsers.py`.
2. JSON-файлы нормализуются (если поля нет — функция подставляет значение по умолчанию).
3. Логика владельцев: `is_owner()` = `OWNER_ID` из `.env` ИЛИ ранг `1` в `admins.json`.
4. Кнопки в InlineKeyboardButton всегда с `text=` (Pydantic в aiogram 3.x).
5. Callback-хэндлеры с одинаковым префиксом должны иметь строгие фильтры (regex), чтобы избежать перехвата.
6. Все графики (matplotlib) сохраняются во временный файл и сразу удаляются после отправки.
7. Модуль `admin_commands.py` удален. Логика разделена на `admin_stats.py`, `admin_roles.py`, `admin_users.py`.
8. В `users.json` у юзера есть поля `rest` (bool) и `rest_end_date` (str). При снятии реста они очищаются.
9. **Атомарная запись:** Все `save_json` идут через `tmp` + `os.replace` + `.bak` (защита от потери данных).
10. **Политика конфиденциальности:** при `/start` бот требует согласия (`agreed_to_privacy: true`). Без согласия доступ к остальным командам заблокирован.
11. **Персональные ссылки:** создаются на 1 вход, живут 2 дня, кэшируются в `users.json` (`invite_link`, `invite_link_expires_at`).
12. **Каскад прокси:** Happ (`socks5://127.0.0.1:10808`) → Karing (`socks5://127.0.0.1:3066`) → напрямую. Если один не работает — пробуем следующий.
13. **Маскировка паролей:** прокси в логах маскируются (`***:***@`).

## 🐞 Известные грабли (Bugs/Gotchas)
1. **Конфликты роутеров:** Специфичные колбэки (с `_yes_`) всегда ставятся ВЫШЕ общих.
2. **Циклический импорт:** Нельзя импортировать `format_role_display` из `role_utils` в `admin_utils` или `parsers` на уровне модуля — это ломает `is_admin`. Middleware должен проверять только `OWNER_ID` и наличие в `users.json`.
3. **Баги в `users.json`:** Поле `role` может содержать как ID (число), так и название роли (строка). В `parsers.py` нужно предусмотреть обработку.
4. **Прокси (Happ):** Если бот не подключается, проверить, что Happ запущен от администратора, и в `.env` стоит `PRIORITY_PROXY=socks5://127.0.0.1:10808`.
5. **`callback_data`:** Лимит 64 байта. Для длинных данных используй ID.
6. **`name` в `create_chat_invite_link`:** Лимит 32 символа.
7. **`ZoneInfo("Europe/Moscow")`:** Требует пакет `tzdata` на Windows.
8. **`my_chat_member`:** Срабатывает только на события бота, а не людей. Для вступления людей — `chat_member`.
9. **`callback is too old`:** Пользователь долго висит на инлайн-кнопке, потом жмёт. Нужен try/except `TelegramBadRequest` в `callback.answer()`.
10. **`set_chat_member_tag`:** Метод **СУЩЕСТВУЕТ** (в новых Bot API). Требует права `can_manage_tags` у бота в группе. Лимит 16 символов, эмодзи запрещены. Не удалять код из `clear_me.py`.

## 📈 Реализованные фичи (актуально на 30.10.2026)
- **Безопасность:** Глобальный Error Handler (пишет в `errors.txt`, уведомления Windows), Graceful Shutdown, проверка чатов при старте.
- **Политика конфиденциальности:** обязательное согласие при `/start` (`agreed_to_privacy`). Ссылки из `.env`.
- **Кэш JSON:** Write-Through Cache в `parsers.py` + кнопка «🧹 Сбросить кэш» в `/settings`.
- **Персональные ссылки:** `create_chat_invite_link` на 1 вход, 2 дня, кэш в `users.json`.
- **Каскад прокси:** Happ → Karing → напрямую.
- **Статистика:** `/stats` с графиком активности (365 дней), `/mynorm` с личным графиком, Топ-5 юзеров (кнопка в `/stats`).
- **Заявки (Этап 1):** Rate-limit на `/apply` (1 мин), защита от повторной подачи, проверка `closed_mode`, автосвобождение ролей (48 часов), атомарная запись, откат при ошибке бронирования роли, причина отклонения отправляется юзеру.
- **Юзеры:** Проверка полноты профиля, сбор старых ников (`aliases.json`), «С возвращением» при `/start`.
- **Ресты:** Хранятся в `users.json`. Авто-снятие по истечении даты. `/unrest` работает по ID.
- **Данные:** `norm_history.json` для графиков, `/sync_norm` для ручного начисления.
- **Атомарная запись:** tmp + os.replace + .bak.
- **Маскировка паролей:** `***:***@`.
- **Неделя по МСК:** `ZoneInfo("Europe/Moscow")`, неделя начинается в сб 21:00.
- **Приветствие:** через `@router.chat_member()`.
- **Парсер варнов:** поддерживает склонения.
- **Middleware:** обход владельца и админов, логирование в `admin_actions.log`.
- **Защита:** от двойного клика при одобрении/отклонении заявок.
- **Очистка данных:** `/free` больше не удаляет юзера из базы (сохраняет `changes_count`). `/clearme` снимает тег (при наличии прав).
- **Удалён бэкдор:** Команды `/register_admin` и `/register_user` удалены.
