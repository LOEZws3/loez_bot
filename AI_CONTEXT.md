# 🧠 AI_CONTEXT.md — Память и заметки для ИИ

Этот файл создан для сохранения контекста разработки бота LoEzF_Bot. 
Любая новая модель ИИ должна прочитать этот файл ПЕРЕД началом работы.

## 🏗️ Архитектурные правила проекта
1. Все данные пишутся/читаются ТОЛЬКО через `src/utils/parsers.py`.
2. JSON-файлы нормализуются (если поля нет — функция подставляет значение по умолчанию).
3. Логика владельцев: `is_owner()` = `OWNER_ID` из `.env` ИЛИ ранг `1` в `admins.json`.
4. Кнопки в InlineKeyboardButton всегда с `text=` (Pydantic в aiogram 3.x).
5. Callback-хэндлеры с одинаковым префиксом должны иметь строгие фильтры (regex), чтобы избежать перехвата (был баг с `findrole_delete_yes_`).
6. Все графики (matplotlib) сохраняются во временный файл и сразу удаляются после отправки.
7. Модуль `admin_commands.py` удален. Логика разделена на `admin_stats.py`, `admin_roles.py`, `admin_users.py`.
8. В `users.json` у юзера есть поля `rest` (bool) и `rest_end_date` (str). При снятии реста они очищаются.

## 🐞 Известные грабли (Bugs/Gotchas)
1. **aiogram 3.23.0:** Метода `set_chat_member_tag` НЕ СУЩЕСТВУЕТ.
2. **Конфликты роутеров:** Специфичные колбэки (с `_yes_`) всегда ставятся ВЫШЕ общих.
3. **Циклический импорт:** Нельзя импортировать `format_role_display` из `role_utils` в `admin_utils` или `parsers` на уровне модуля — это ломает `is_admin`. Middleware должен проверять только `OWNER_ID` и наличие в `users.json`.
4. **Баги в `users.json`:** Поле `role` может содержать как ID (число), так и название роли (строка). Это вызывает `KeyError` при попытке использовать его как ключ. В `parsers.py` нужно предусмотреть обработку.
5. **Прокси (Happ):** Если бот не подключается, нужно проверить, что Happ запущен от администратора, и в `.env` стоит `PRIORITY_PROXY_False_protocol=socks5://127.0.0.1:10808`.

## 📈 Реализованные фичи (актуально на 24.10.2026)
- **Безопасность:** Глобальный Error Handler (пишет в `errors.txt`, уведомления Windows), Graceful Shutdown, проверка чатов при старте.
- **Статистика:** `/stats` с графиком активности (365 дней), `/mynorm` с личным графиком, Топ-5 юзеров (кнопка в `/stats`).
- **Заявки:** Rate-limit на `/apply` (1 мин), автосвобождение ролей (48 часов), причина отклонения отправляется юзеру.
- **Юзеры:** Проверка полноты профиля, сбор старых ников (`aliases.json`), «С возвращением» при `/start`.
- **Ресты:** Хранятся в `users.json` и `roles_status.json`. Авто-снятие по истечении даты (проверка в `main.py`). Команда `/unrest` работает по ID.
- **Данные:** `norm_history.json` для графиков, `/sync_norm` для ручного начисления.
- **Новое:** Политика конфиденциальности и правила пользования с обязательным подтверждением (в разработке).
