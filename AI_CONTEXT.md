# 🧠 AI_CONTEXT.md — Память и заметки для ИИ

Этот файл создан для сохранения контекста разработки бота LoEzF_Bot. 
Любая новая модель ИИ должна прочитать этот файл ПЕРЕД началом работы.

## 🏗️ Архитектурные правила проекта
1. Все данные пишутся/читаются ТОЛЬКО через `src/utils/parsers.py`.
2. JSON-файлы нормализуются (если поля нет — функция подставляет значение по умолчанию).
3. Логика владельцев: `is_owner()` = `OWNER_ID` из `.env` ИЛИ ранг `1` в `admins.json`.
4. Кнопки в InlineKeyboardButton всегда с `text=` (Pydantic в aiogram 3.x).
5. Callback-хэндлеры с одинаковым префиксом должны иметь строгие фильтры (regex), чтобы избежать перехвата (был баг с `findrole_delete_yes_`).
6. Все графики (matplotlib) сохраняются во временный файл и сразу удаляются после отправки.
7. Модуль `admin_commands.py` удален. Вся его логика разделена на `admin_stats.py`, `admin_roles.py`, `admin_users.py`.

## 🐞 Известные грабли (Bugs/Gotchas)
1. **aiogram 3.23.0 (обновлено с 3.17.0):** Метода `set_chat_member_tag` НЕ СУЩЕСТВУЕТ. Удаление тегов не поддерживается API.
2. **Конфликты роутеров:** Специфичные колбэки (с `_yes_`) всегда ставятся ВЫШЕ общих (просто с `_delete_`).
3. **Вызов `cmd_settings` из колбэка:** Если передать `callback.message` в команду, бот определит отправителем САМОГО СЕБЯ, и доступ по `is_owner` упадет. Нельзя так делать, нужно обновлять клавиатуру через `edit_reply_markup`.
4. **Импорты после рефакторинга:** Если при запуске вылетает `No module named 'handlers.admin_commands'`, нужно найти этот импорт в `keyboards.py`, `base_commands.py` или `middlewares` и заменить на `admin_stats`, `admin_roles` или `admin_users`.
5. **PyLance и winotify:** Если VS Code подчеркивает `winotify` красным, но бот работает — это значит, что выбран неверный интерпретатор в настройках (смотрит в старую папку `.venv` от другого проекта). Нужно выбрать `LoEZF_Bot/.venv/Scripts/python.exe`.

## 📈 Реализованные фичи
- **Безопасность:** Глобальный Error Handler (пишет в `errors.txt`, показывает уведомления Windows), Graceful Shutdown.
- **Статистика:** `/stats` с графиком активности за 365 дней (на основе истории норм), `/mynorm` с персональным графиком.
- **Заявки:** Rate-limit на `/apply` (1 минута), автосвобождение ролей (48 часов), причина отклонения отправляется юзеру в ЛС.
- **Юзеры:** Проверка полноты профиля во флуде (нью — раз в 1 час, остальные — раз в 12 часов), сбор старых ников/алиасов в `aliases.json`.
- **Управление:** `/giverest [ID] [дней]` для отправки в рест за другого юзера.
- **Данные:** `norm_history.json` для хранения истории активности по неделям.
