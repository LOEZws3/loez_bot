## [5.5.0] - 2026-09-06

### 🚀 Добавлено

#### Управление администраторами
- `/promote [ID или @username]` — повысить пользователя до администратора (только владелец)
- `/demote [ID или @username]` — понизить администратора (только владелец)
- `/setrank [ID] [ранг]` — назначить ранг (1-Владелец, 2-Админ, 3-Модератор)
- Обновлён список администраторов с рангами
- Добавлена проверка на владельца

#### Интерфейс настроек (для владельца)
- `/settings` — главное меню настроек с инлайн-кнопками
- Настройка набора ролей (вкл/выкл)
- Настройка напоминалки (вкл/выкл)
- Настройка приветствия для новых пользователей
- Настройка авто-снятия реста
- Настройка кулдауна кала (5-120 сек)
- Настройка кулдауна кал-фал (10-300 сек)
- Настройка максимальной длительности реста (1-30 дн.)
- Просмотр всех текущих настроек
- Сброс настроек к стандартным

#### Диагностика
- `/diag` — полная диагностика системы (владелец)
  - Информация о боте
  - Проверка файлов
  - Проверка базы данных
  - Проверка токена
  - Проверка чатов
- `/check_chats` — диагностика чатов (владелец)
  - Проверка статуса во флуд-чате
  - Проверка статуса в админ-группе

#### Система логирования
- Добавлено логирование всех действий администраторов
- Добавлено логирование изменений настроек
- Добавлено логирование команд и ошибок

### 🔧 Изменено

#### Напоминалка
- Добавлен `chat_member_router` в `__init__.py`
- Исправлена работа напоминалки для незарегистрированных пользователей
- Добавлена проверка на наличие пользователя в базе

#### Команды во флуде
- Добавлены проверки `if message.chat.id == GENERAL_CHAT_ID`
- Запрещены во флуде: `/apply`, `/free`, `/rest`, `/cancel_request`, `/regc`, `/unregc`, `/update`, `/start`, `/help`, `/about`, `/aboutme`
- Разрешены во флуде: `/members` (только количество), `/roles` (без кнопок), `/call`, `/callfal` (для админов)

#### Управление клавиатурой
- Добавлены команды `/hide` и `/menu` для управления клавиатурой
- Во флуде клавиатура не показывается

### 🐛 Исправлено

- Исправлена напоминалка для незарегистрированных пользователей
- Исправлены команды, работающие во флуде
- Исправлен импорт `chat_member_router` в `__init__.py`

## 🔄 Как обновлять

При каждом значимом изменении добавляйте запись в этот файл:

1. **Дата** — в формате `YYYY-MM-DD`
2. **Версия** — увеличивайте номер (мажорная.минорная.патч)
3. **Категория** — `[ДОБАВЛЕНО]`, `[ИЗМЕНЕНО]`, `[ИСПРАВЛЕНО]`, `[УДАЛЕНО]`
4. **Описание** — краткое описание изменения
